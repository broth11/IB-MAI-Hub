## First study page: lesson 209 (AHL 2.7)

`docs/data/lessons/209.json`, Domain & Range, Composite, Inverse (SL 2.2 and AHL 2.7). Sections: a decision check (does the function have an inverse?), the composite and inverse method, exam wording traps, and a written response. No GDC section yet (no captures for this topic). The video inverts f(x)=x^2-2 without restricting the domain; the page adds the restriction and the domain of the inverse, and says so in the flags. Values were computed with sympy; the page check passes. On the branch `lesson/ahl-2-7`; merging the pull request publishes it.

The page also uses the new `corrections` box (two "Not in the video" entries: the missing domain restriction at 9:56 and the missing domain of an inverse at 10:35). A GDC section for it (graph a function and its inverse, check the reflection in y = x, Zoom Square) is planned but not built; see `notes/gdc-209-capture-plan.md`. The page replaced the AP-style `wording` and `frq` sections with `exam` ("In the exam", built from the question bank statistics plus markscheme reading) and `question` (an exam-style question with a tick-off markscheme). `docs/data/exam.json` is generated by `scripts/build_exam_stats.py` (HL applications and interpretation questions, 2021 to 2025). Findings for AHL 2.7: 14 questions, 12 on Paper 1, command term Find in 12; inverses often of rational, exponential or logarithmic functions, often "domain not required"; the video only inverts a quadratic and a square root, so a third correction was added. Three codes (AHL 1.11, AHL 3.11, AHL 4.12) had no HL question in the bank.

The lesson also has an `inverse` explorer (`docs/js/explorers/inverse.js`): equal-scale grid, draggable horizontal line for the one-to-one test, reflection in y = x, mirror point, quadratic restricted to either side of its vertex. All nine tested states matched values computed in Python.

Engine fixes made while building it: the response box placeholder no longer says "statistical symbols"; a `frq` section can set its own `note`.

## Home page is organized by syllabus code

The home page lists the 78 codes in `docs/data/syllabus.json` (short titles written by Claude, not IB text), each with the videos whose `syllabus` list includes it. A video that covers several codes appears under each (marked "also covers this" where the code is not its first). A code with no video shows a red "No video yet" row; a code that a video only mentions briefly (a lesson's `syllabusPartial` list) shows an amber row. The Gaps tab lists both (12 of 78 on 5 Nov 2026: 11 with no video, 1 brief). To fill a gap: add the video to the playlist data, give it a `syllabus` list, and the row updates.

For each of the 78 codes, a keyword list was searched in all 82 transcripts and every video scored on how many of the code's terms it uses; passages were then read for the doubtful cases. Results:

- Added: AHL 1.11 to lesson 105 (it teaches the sum of an infinite geometric sequence).
